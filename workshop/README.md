# Workshop

How Lyra gets made. None of this is needed to use or build Lyra; it's here
because the process is part of the project, and it's all open anyway.

Lyra is designed, directed and tested by Rhodexa (Rhodune! Lab), and
implemented in Rust by Claude, Anthropic's AI model, working session by
session from these notes. The files here are written for that loop, so
they speak to "you" and "me" and assume the context of the last session.

| file | what |
|---|---|
| [JOURNAL.md](JOURNAL.md) | Rhodexa's friction and wishes from real use; what gets worked on comes from here |
| [DONE.md](DONE.md) | every journal item that got finished, with the commit that did it |
| [NOTES.md](NOTES.md) | known limits and leftovers noticed while building |
| [design/](design/README.md) | the UI design drop-box: mockups, the HTML widget catalogs that are the visual spec, the port status |

For how Lyra itself is put together, read [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
Octavia keeps its own workshop in [plugins/octavia/workshop](../plugins/octavia/workshop).
