# Starter Kit — credits

Sixty-five drum and percussion one-shots, all **CC0 1.0 (public domain)**: free to use, change and
redistribute for any purpose, no attribution required. We credit the authors anyway, with thanks.

**Where they come from.** Selected from the samples bundled with [Sonic Pi](https://sonic-pi.net)
v3.2.2 (`etc/samples`), which in turn come from [Freesound](https://freesound.org). Each file's
author, source and licence below are copied from Debian's reviewed copyright file for Sonic Pi
(`sonic-pi_3.2.2~repack-8_copyright`), which records every sample as CC0. Sonic Pi's *loops*
(e.g. the Amen break) are deliberately **not** included: a loop recorded from someone else's record
isn't the uploader's to put in the public domain.

File names are Sonic Pi's, so each one can be traced back.
